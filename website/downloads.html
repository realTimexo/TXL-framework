What each release contains.

The installer downloads the latest CLI package; the VSIX and Windows sample are optional convenience artifacts.

Txl.Cli NuGet toolInstall the compiler as a per-user .NET global tool named `txl`.
VS Code `.vsix`Install with “Extensions: Install from VSIX...” and use the compiler for preview.
Windows x64 example ZIPIncludes the AllFeatures app and its `content` assets; extract the complete folder before running.
The CLI needs the .NET 9 SDK to build TXL projects. The generated Windows app is self-contained; project assets such as video and images remain beside the executable.
