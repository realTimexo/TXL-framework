Assets and layout / 5 minute read

Images, video, and fixed coordinates.

A desktop project can use local assets for reliable offline distribution, or an HTTP(S) source when a network dependency is appropriate. The layout and media model is intentionally simple.

Fit an image into a smaller box

Assign a class in a `style (` block and set `size`, `width`, or `height`. An image's proportions remain intact when the runtime fits it into the requested dimensions.

style (
  logoMark:
    size = 112
)
image(logoMark) = assets/txl-logo.png

`size` sets a uniform-fit box. A width or height sets that side; leave the other side unconstrained to preserve the image's natural ratio.

Keep project files together

Put files beneath the project folder and reference them with relative paths. On publish, TXL places project content beside the executable in its `content` folder. Ship that folder along with the EXE. Absolute paths and paths escaping the project root are rejected to keep output predictable.

MyApp/
  info.json
  main.txl
  assets/
    txl-logo.png
    sample.mp4

HTTP and HTTPS URLs are supported, but remote assets depend on a network connection and the remote host staying available. Local project files are usually the better choice for offline apps.

Use the video player controls

The `video` element generates a WPF media control with Play and Pause buttons. `autoplay = false` disables automatic start; `loop = true` repeats playback. Provide dimensions to fit it into a known space.

video = assets/sample.mp4
autoplay = false
loop = true
width = 480
height = 270

Video support is platform-dependent. WPF uses Windows media components and installed codecs; a file that plays in one environment may not play on another. Test the target PCs and codecs. The current implementation has not received visual playback verification across Windows versions.

Place elements with `x` and `y`

For precise fixed positioning, set `layout = absolute` on the containing group. Then use `position = x18 y3` on each control or its style. Coordinates are fixed canvas offsets, not responsive constraints.

group = toolbar (
  layout = absolute
  text = Search
  position = x18 y3
  button = Go
  position = x18 y48
)

Use vertical or horizontal stack layout when you want children arranged in sequence. Use absolute positioning when you want explicit coordinate placement.

For WPF media, focus and scaling, validate a real Windows build. The cross-platform compiler tests do not simulate a desktop or video codec.
