Language guide / Desktop runtime

Windows, media, and keys.

These features connect TXL source to native WPF window and media controls. Paths and values are checked before the generated application runs.

Windows blockImage sourcesVideo playbackPositioningKeyboard

Set the window

Put a `windows (` block in the app source. The title and icon are project-relative values. Size uses width first, height second; the parser accepts 200–7680 by 150–4320. Mode choices are `normal`, `maximized`, `fullscreen`, and `borderless`.

windows (
  title: TXL Photo Viewer
  icon: assets/app.ico
  size: 1100x760
  mode: maximized
)

Omit a setting to inherit its `info.json` default: app name or optional window title, project icon, project width and height, and optional project mode. `normal` is the default mode.

Size images and pick a source

Local images use project-relative paths such as `assets/logo.png`. The compiler copies project content beside the executable. Absolute and parent-traversal paths are not accepted by the generated runtime. A URL must start with HTTP or HTTPS.

style (
  mark:
    size = 128
)
image(mark) = assets/logo.png
image = https://example.org/banner.png

Image `size` sets a uniform-fit box; `width` or `height` sets one side independently. The pixels keep their proportions. Remote files require an internet connection at runtime.

Play a local or remote video

The `video` element uses a WPF `MediaElement` and adds Play/Pause controls. Its source may be a local project asset or an HTTP(S) address. Use `autoplay = false` to wait for the Play button; `loop = true` repeats the clip.

video = assets/sample.mp4
autoplay = false
loop = true
width = 480
height = 270
WPF media support depends on installed Windows codecs and the exact file or stream format. Remote playback and codec behavior have not been visually verified on every Windows release; test the target device.

Place controls at fixed coordinates

Choose `layout = absolute` for the containing group, then assign fixed coordinates with `position = x18 y3`. Position can be set directly on the group or an element, or inherited from a style section. Responsive resizing rules are not part of the current layout system.

group = canvas (
  layout = absolute
  text = Positioned label
  position = x18 y3
  button = Continue
  position = x18 y48
)

Handle an Enter key without eating input

Attach a `keydown` class action to an input. A `key` property filters which key runs the action. Since the handler runs on a focused control, ordinary typing continues to edit the text.

actions (
  searchField(keydown):
    key = Enter
    alert = Search submitted
)
input(searchField) = Type a query, then press Enter

This simple event form does not implement multi-key chords or a global shortcut manager. Read variables and native alert boxes for the alert action itself.
