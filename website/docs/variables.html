Language guide / Values

Variables, conditions, and alerts.

TXL has compile-time variables for source expansion and persistent runtime state for values an app changes while it is open. These are different jobs, with different syntax.

Compile-time valuesIf conditionsRuntime stateAlert boxes

Compile-time values with `set`

`set = name:value` stores a value while TXL compiles. Use `${name}` to insert it into source. It is not editable by the user after the app launches.

set = username:Ada
set = access:admin

text = Hello, ${username}.
text = Access level: ${access}

Check a value with `if`

Use `if = name == value (` or `if = name != value (`. TXL compares strings without case sensitivity. The block is included during compilation only; it does not react to runtime changes.

set = access:admin

if = access == admin (
  text = You can manage this list.
)

if = access != admin (
  text = You can view this list.
)

Truth values can also be used directly: `if = true (` includes the block and `if = false (` skips it. Blocks close with their own standalone `)`.

Values that change while the app is running

Use `state = key:initial-value` for runtime state. TXL writes state to a JSON file under the current Windows user's `%LocalAppData%\TXL\` folder. Use `bind = key` on an input or checkbox to read and update the value.

state = visitor:Ada

input = Type a name
bind = visitor

text = Name now:
text = Ada
bind = visitor

Actions such as `set`, `append`, `clear`, `toggle`, and `math` update runtime state. A saved value replaces the declared initial value on later launches. See the feature page for the scope and limits of persistence.

Show a native Windows alert box

Put `action = alert("message")` after a button. The compiler attaches it to that button and the runtime shows a basic native Windows message box.

group = savePanel (
  button = Save
  action = alert("Your changes were saved.")
)

To use a class action instead, declare `className(click):` inside an `actions (` block and add `alert = Your message`. Then assign that class to the control as `button(className) = Save`.

actions (
  saved(click):
    alert = Your changes were saved.
)
button(saved) = Save

TXL also supports `success(message)`, a Yes/No `confirm(message)`, and `prompt(state,title)`. These are simple native dialogs, not custom form windows.
