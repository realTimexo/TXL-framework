Version history / Changelog

What changed, and what was tested.

A readable record of shipped TXL behavior. Release assets and tags live in GitHub Releases; this page summarizes the source changes without claiming unverified Windows behavior.

22 November 2026v0.7.0

Singular window syntax and one-command updates.

Use the clearer window ( block in new projects; existing windows ( files remain compatible. Run txl --update from any folder to find the newest stable compiler package on GitHub Releases and update the per-user global tool.

LANGUAGE

Use window (

The starter, AllFeatures sample, editor snippets, and docs use the singular spelling. The parser still accepts the earlier plural block.

CLI + INSTALLER

Update TXL with one command

txl --update reads the latest stable release, verifies the package size and SHA-256 digest, and runs a version-specific .NET global-tool update. The installer now pins the release version too.

21 November 2026v0.6.0

More practical syntax, clearer builds.

This version adds window controls, media support, keyboard actions, image sizing, a current-folder CLI, and a more complete editor experience.

LANGUAGE + RUNTIME

More direct desktop syntax

Use text.headline, `windows (` settings for title, icon, size, and display mode, and `position = x18 y3` on an absolute Canvas. Images accept local and HTTP(S) sources and image styles set dimensions. Video adds Play/Pause controls with optional autoplay and looping.

INTERACTION

Keyboard and saved values

Class-based click, hover, and filtered key-down actions can trigger runtime behavior. The familiar `Enter` key name is normalized for WPF. Runtime state remains stored by project identity, even when the display title is customized.

CLI + PACKAGING

Use `txl` from a project folder

The .NET global tool exposes `txl --build`, `--check`, `--preview`, `--version`, and `--help`. The installer bootstraps a per-user .NET 9 SDK if needed and installs a published compiler package from GitHub Releases.

EDITOR + DOCS

Better source editing

VS Code completion, snippets, media paths, grammar coloring, file-icon support, and the `!` scaffold now cover the expanded syntax. The repository includes a full feature sample, language reference, install guide, contribution notes, and static site.
