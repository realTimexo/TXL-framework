Version history / Changelog

What changed, and what was tested.

A practical record of TXL behavior and release validation. Stable packages and preview builds are listed separately so installation instructions remain clear.

25 November 2026v0.9.0-preview.1

More useful runtime APIs, still a focused language.

The preview adds imported libraries and custom single-return functions; JSON arrays and objects; app-data file operations; asynchronous HTTP GET and JSON POST; repeating UI timers; and SQLite with named bound parameters and explicit transactions.

SAFETY + ERRORS

Safer actions

Imports and app-data paths reject traversal and symbolic links. SQL values use parameters. Runtime action wrappers can await an operation and place its exception message in state.

UPDATER RECOVERY

Isolated Windows fallback

The targeted `.store\txl.cli` access-denied failure installs a verified version into a fresh per-user tool path rather than deleting the locked global cache. The original Windows machine still needs a direct permission test.

Preview note. General-purpose user-written async/await, arbitrary socket networking, background workers, and multi-statement function bodies are not included. HTTP is asynchronous internally; SQLite actions run synchronously. WPF visuals and the exact updater permissions issue require real Windows user-session checks.

Find the preview package on GitHub Releases and follow the isolated installation instructions on Get Started. The normal installer and txl --update remain on stable releases.

23 November 2026v0.8.0 · stable

Clearer compile-time control flow and richer WPF styling.

Added compile-time if/else, five text heading levels, group styling and alignment, rounded buttons, basic borders and shadows, trusted HTML embedding, safe mail links, compiled multi-page navigation, and validated HTTPS font packaging. The stable updater checks GitHub Releases, verifies the package digest, and updates the per-user global tool.

All 39 regression tests passed at release time; GitHub Actions built and packaged the Windows CLI, extension, and sample app. Visual WPF interaction still needs manual Windows testing.

22 November 2026v0.7.0

Singular window syntax and one-command updates.

New source uses window (; legacy windows ( remains accepted. The updater checks the latest stable GitHub release, verifies the NuGet asset's size and SHA-256 digest, and updates the global tool.
